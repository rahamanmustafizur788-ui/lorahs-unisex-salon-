How to use the Character Counter

About the Character Counter

See character counts with and without spaces, plus the number of lines, to stay within limits for posts, bios, SMS and meta descriptions.

Frequently asked questions

Do emojis count as one character?

Some emojis are made of several code units, so the count may be higher than you expect.
