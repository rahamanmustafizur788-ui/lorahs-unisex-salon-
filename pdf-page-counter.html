PDF Page Counter

Count the pages in one or more PDFs.

How to use the PDF Page Counter

  1. Choose your PDF or image file(s).
  2. Set any options shown.
  3. Click the button, then download the result.

About the PDF Page Counter

Quickly see how many pages one or more PDFs contain, handy before printing or when a form has a page limit. Select several files to count them in one go.

Frequently asked questions

Does it show page sizes?

No, only the number of pages for each file.

Privacy

Your PDFs are processed locally in your browser and are never uploaded.
