PDF Compressor

Shrink PDF size by re-encoding pages as images.

How to use the PDF Compressor

  1. Choose your PDF or image file(s).
  2. Set any options shown.
  3. Click the button, then download the result.

About the PDF Compressor

This tool renders each page and saves it again as a compressed image inside a new PDF, which can greatly reduce scanned or image-heavy PDFs. The trade-off is that text becomes part of the image and can no longer be selected or searched.

Frequently asked questions

When should I not use it?

Avoid it for PDFs where you need selectable text or sharp vector graphics. If the result is not smaller, keep the original.

Privacy

Your PDFs are processed locally in your browser and are never uploaded.
